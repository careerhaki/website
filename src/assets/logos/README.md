# Alumni-employer logos

Logos of companies where CareerHaki alumni work, for the logo strip ("Where our
alumni work.", motion L, the spotlight belt). Supplied by Nithish. Shown as
places alumni work, never as clients. Each logo's alternative text is the
company's official name (column 2).

Not used on any page yet: the strip is built once the list is complete.

## How the files were prepared (21 November 2026)

- SVGs: optimised with svgo 3.3.2 (metadata and editor data removed), and the
  `viewBox` trimmed to the artwork so every logo sits on the same baseline
  without hidden padding. Colours and shapes unchanged except where noted.
- PNGs: trimmed to the artwork; transparency kept.
- One colour at rest is done in CSS, so only the full-colour file is kept.
